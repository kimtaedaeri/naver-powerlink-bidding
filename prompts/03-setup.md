# ⚙️ 03 — Chat-driven 셋업 (3분)

## 사장님이 채팅에 입력할 한 마디

> **"내 광고 계정 연결해줘"**

또는

> **"셋업해줘"**

---

## 전제 조건

- `.env` 파일에 네이버 API 키 3개가 들어있어야 함
- 없으면 → `prompts/02-api-key-naver.md` 먼저

---

## Claude 절차 (단계별)

### 1단계 — 키 검증

```bash
python scripts/verify_keys.py
```

- 성공이면 "✅ 인증 성공. 다음 단계로 가겠습니다." 출력
- 실패면 → `.env` 다시 확인 안내, `prompts/02-api-key-naver.md` 재진행

### 2단계 — 광고그룹 발견

```bash
python scripts/discover_adgroups.py
```

→ JSON 출력. 예:
```json
{
  "adgroups": [
    {"id": "grp-a001-...", "name": "all_keyword_none_all_key", "campaign": "캠페인1"},
    {"id": "grp-a001-...", "name": "다른광고그룹", "campaign": "캠페인2"}
  ]
}
```

이걸 사장님께 한국어로 보여준다:

```
📂 사장님 광고 계정에 광고그룹 N개가 있어요:

   [1] all_keyword_none_all_key  (캠페인1)
   [2] 다른광고그룹              (캠페인2)

어떤 그룹들을 김태대리가 관리할까요?
- "1번" 또는 "1, 2번" 또는 "전부 다"
```

### 3단계 — 사장님 선택 받기 + yaml 생성

사장님이 "1번" 또는 "전부 다" 답변 후:

```bash
python scripts/setup_yaml.py --groups <id1>,<id2>
```

(전부 다는 `--all`)

→ `keywords.yaml` 자동 생성. 키워드는 네이버에서 자동 가져옴.

### 4단계 — 정책 기본값 안내

```
✅ 셋업 완료! 키워드 N개가 등록됐어요.

기본 정책:
- 목표 순위: 3위
- 최대 입찰가: 10,000원
- 최소 입찰가: 100원
- 1회 조정 단위: 500원

이대로 가도 되고, 사장님이 직접 수정하셔도 돼요.
숫자 바꾸고 싶으시면: "목표 순위를 2위로 바꿔줘" 같이 말씀하세요.
```

### 5단계 — 첫 안전 시뮬

```
이제 처음으로 실제 광고 계정에서 입찰가를 조회해보겠습니다.
**실제로 변경하지는 않습니다.** 결과만 보여드릴게요.
```

```bash
python -m powerlink_pilot run --dry-run
```

결과를 한국어 표로 요약:

```
📊 사장님 광고 계정 시뮬레이션 결과

키워드          현재 입찰가  →  새 입찰가    조정
─────────────────────────────────────────────
토지담보대출    8,500원   →   9,000원    ⬆ 500원 ↑
아파트담보대출  9,200원   →   9,700원    ⬆ 500원 ↑
...

처리 N건 / 스킵 0건 / 실패 0건

이 결과가 마음에 드시면 → "진짜로 입찰 변경해줘"
조정하고 싶은 부분이 있으면 → 키워드 이름과 함께 말씀해 주세요
```
