# 🎬 01 — 데모 (API 키 없이 30초)

## 사장님이 채팅에 입력할 한 마디

> **"결과 보여줘"**

또는

> **"데모 돌려줘"**

---

## Claude 절차

1. `python -m powerlink_pilot run --sample` 실행 (Bash 도구)
2. 출력 그대로 보여주되, **마지막에 한국어 요약** 추가
3. 다음 행동 안내

### 출력 예시 + 요약 형식

```
[원본 출력]
🚀 powerlink-pilot — sample mode
📊 내장 샘플 (3개)
  키워드_쉬움      순위 7  입찰  2,500원 → 목표 3  새 입찰  3,000원  ⬆ raise
  ...
```

→ 그 아래에 다음과 같이 요약:

```
📌 사장님께 드리는 요약

방금 3개의 가상 키워드로 입찰 자동화 시뮬레이션을 돌렸습니다.

- 키워드_쉬움: 순위 7 → 목표 3 (입찰가 ↑ 500원 조정)
- 키워드_중간: 순위 8 → 목표 3 (입찰가 ↑ 500원 조정)
- 키워드_경쟁심한: 순위 11 → 목표 2 (입찰가 ↑ 800원 조정)

자동화 핵심 원리:
✅ 한 번에 너무 크게 안 바꿉니다 (step만큼만)
✅ 최대 입찰가 안에서만 움직입니다 (예산 안전)
✅ 다시 돌리면 순위가 목표에 더 가까워집니다 (수렴)

이게 마음에 드시면, 사장님의 실제 광고 계정과 연동할 수 있어요.
→ "API 키 발급 도와줘" 또는 "내 광고 계정 연결해줘" 라고 말씀하세요.
```

---

## 만약 명령이 실패하면

- `python` 명령이 없다는 에러 → "Python이 설치 안 되어 있어요. Claude Code 설치 가이드 다시 확인해 주세요"
- `powerlink_pilot` 모듈 없음 → `.venv/bin/pip install -e .` 다시 실행 후 재시도
- 그 외 → `prompts/99-help.md` 진단 절차
