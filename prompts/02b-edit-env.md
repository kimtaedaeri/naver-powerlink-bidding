# 📝 02b — 메모장으로 `.env` 직접 편집 (5분)

> 🔒 **이게 김태대리 채널의 보안 약속입니다.**
> API 키는 Claude(AI)도, 김태대리도, 그 누구도 보지 않습니다. **사장님이 직접 파일에 적습니다.**

---

## 준비물

- 네이버 검색광고에서 발급받은 키 3개:
  - `API_KEY`
  - `SECRET_KEY`
  - `CUSTOMER_ID`
- 없으시면 → [02-api-key-naver.md](02-api-key-naver.md) 먼저

---

## 🍎 Mac 사용자 — 5단계

### 1️⃣ 터미널 열기

`Spotlight`(⌘ + Space) → "터미널" 검색 → Enter

> 이미 Claude Code 켜져있어도 됩니다. 새 터미널 창을 따로 여세요.

### 2️⃣ 프로젝트 폴더로 이동

터미널에 그대로 입력:

```bash
cd ~/Documents/kimtaedaeri/naver-powerlink-bidding
```

### 3️⃣ `.env` 파일 만들기 (없으면)

```bash
cp .env.example .env
```

> 이미 만들어져 있으면 "이미 있다"는 메시지가 뜹니다. 무시하셔도 OK.

### 4️⃣ TextEdit 으로 열기

```bash
open -a TextEdit .env
```

또는 VS Code 사용 중이면:

```bash
code .env
```

### 5️⃣ 키 3개 붙여넣기 + 저장

파일이 열리면 다음과 같이 보입니다:

```
# 네이버 검색광고 API
NAVER_API_KEY=
NAVER_SECRET_KEY=
NAVER_CUSTOMER_ID=

# Anthropic API (AI 기능 v0.3+ 사용 시)
ANTHROPIC_API_KEY=
```

각 `=` **바로 뒤에** (공백 없이) 사장님의 키 값을 붙여넣으세요:

```
NAVER_API_KEY=0100000000abc123def456...
NAVER_SECRET_KEY=A1B2C3D4E5F6...
NAVER_CUSTOMER_ID=1234567
```

⚠️ 주의:
- `=` 앞뒤에 **공백 절대 X** (있으면 인식 안 됨)
- 키 값에 **따옴표 X**
- 줄바꿈 X (키 값이 길어도 한 줄에)

**저장**: ⌘ + S → **닫기**: ⌘ + W

## ✅ 입력 끝났으면

Claude(김태대리) 채팅창으로 돌아와서 한 마디:

> **"키 입력 끝났어. 검증해줘"**

또는

> **"verify"**

김태대리가 `scripts/verify_keys.py` 를 실행해서 다음과 같이 확인:

```
🔐 네이버 검색광고 API 키 검증 중...
✅ 인증 성공
   API_KEY:     ••••cd12
   SECRET_KEY:  ••••ab34
   CUSTOMER_ID: 1234567
```

→ 키 값은 **마스킹**되어 마지막 4자리만 보입니다. 화면 녹화에도 안전.

## ⛔ 절대 하지 말 것

- ❌ **Claude 채팅창에 API 키 직접 입력**
  - 만약 실수로 입력하셨다면: 즉시 네이버 콘솔에서 키 재발급
- ❌ **카카오톡·메일·메모앱에 키 저장**
- ❌ **`.env` 파일을 다른 사람과 공유**
- ❌ **GitHub에 `.env` 커밋** (`.gitignore` 가 막아주지만 한번 더 확인)
- ❌ **영상 촬영 중 `.env` 파일 화면에 띄우기**

---

## 🆘 키 검증 실패하면

```
❌ 인증 실패 — API 키 또는 비밀 키가 맞지 않습니다
```

이런 메시지가 뜨면:

1. **다시 `.env` 열기** — 위 4단계 명령 다시 실행
2. **확인할 것**:
   - `=` 앞뒤 공백 있는지
   - 키 값이 잘렸는지 (긴 키는 복사 중 끊길 수 있음)
   - 큰따옴표 들어갔는지 (들어가면 안 됨)
3. **저장 후 다시 "verify"** 명령

3번 다시 시도해도 실패하면:
- 네이버 콘솔에서 비밀 키 재발급 (한 번 본 후 다시 못 봄)
- 새 비밀 키로 `.env` 업데이트

---

## 🔒 왜 이렇게 하나요?

다른 AI 자동화 도구들은 사장님 키를 자기 서버에 받아 저장합니다. 그래서:
- 그 회사가 망하면 → 사장님 키 분실 위험
- 그 서버가 해킹당하면 → 모든 사용자 키 유출
- AI 채팅에 키를 입력하면 → 30일간 서버에 로그 남음

**김태대리는 다릅니다.**
- 사장님이 직접 `.env` 편집 → AI는 키를 절대 본 적 없음
- 키는 **사장님 컴퓨터에만** 존재
- 김태대리 채널이 사라져도 사장님 키는 안전

이게 김태대리 채널의 약속이고 차별점입니다.
