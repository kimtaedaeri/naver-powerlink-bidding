# 🔑 02 — 네이버 검색광고 API 키 발급 (5분)

## 사장님이 채팅에 입력할 한 마디

> **"API 키 발급 도와줘"**

또는

> **"네이버 광고 연결하고 싶어"**

---

## Claude 절차

사장님께 발급 단계를 **3단계로 쪼개서** 안내. 한 번에 다 보여주지 말고, 한 단계씩 진행하며 "다음" 신호를 기다린다.

### 1단계 — 네이버 검색광고 콘솔 접속

```
사장님, 먼저 네이버 검색광고 계정이 필요해요.

📍 다음 주소를 브라우저에서 열어 주세요:
https://manage.searchad.naver.com/customers

→ 사장님 네이버 아이디로 로그인하시면 검색광고 관리 페이지가 열립니다.

광고 계정이 이미 있으시면 → "있어" 또는 "다음"
처음이시면 → "처음이야" (가입 안내 드릴게요)

로그인 후 우측 상단에 보이는 **Customer ID(숫자)** 도 메모해 주세요.
```

### 2단계 — API 사용 관리 페이지에서 키 발급

사장님이 "다음" 하면:

```
좋아요. 이제 키 2개를 발급하겠습니다.

📍 같은 페이지에서:
   상단 메뉴 → "도구" → "API 사용 관리" 클릭

📍 페이지가 열리면:
   "API 라이선스 발급" 버튼 → 약관 동의 → 발급

발급되면 화면에 2개 값이 나옵니다:
   - API 키 (영문+숫자 짧은 문자열)
   - 비밀 키 (긴 문자열, ⚠️ 화면 닫으면 다시 못 봅니다)

두 값을 안전한 곳에 복사하고, **여기 채팅창에 알려주세요.** 형식:

API_KEY: (값)
SECRET_KEY: (값)
CUSTOMER_ID: (값)
```

### 3단계 — `.env` 파일 자동 생성

사장님이 3개 값을 알려주면, Claude이 `.env` 파일을 작성한다:

1. `Write` 도구로 다음 내용을 `.env`에 작성:
   ```
   NAVER_API_KEY=<사장님_값>
   NAVER_SECRET_KEY=<사장님_값>
   NAVER_CUSTOMER_ID=<사장님_값>
   ANTHROPIC_API_KEY=
   ```
2. `python scripts/verify_keys.py` 실행으로 키 검증
3. 결과를 사장님께 한국어로 보고:
   - 성공: "✅ API 키 정상 작동합니다. 이제 광고 계정을 셋업할게요."
   - 실패: "❌ 키가 맞지 않는 것 같아요. 다시 확인해 주시겠어요?"

## 사장님이 모르는 게 있을 때

- "Customer ID가 어딨어요?" → "검색광고 관리 페이지 우측 상단, 사장님 이름 옆 숫자입니다"
- "비밀 키를 못 봤어요" → "괜찮아요. 같은 페이지에서 다시 발급받으시면 새 비밀 키가 나옵니다"
- "광고 계정이 없어요" → 네이버 광고주 가입 안내 (시간 더 걸림, 별도 영상 추천)
