# 🔑 02 — 네이버 검색광고 API 키 발급 (5분)

## 사장님이 채팅에 입력할 한 마디

> **"API 키 발급 도와줘"**

또는

> **"네이버 광고 연결하고 싶어"**

---

## Claude 절차

사장님께 발급 단계를 **3단계로 쪼개서** 안내. 한 번에 다 보여주지 말고, 한 단계씩 진행하며 "다음" 신호를 기다린다.

### 1단계 — 네이버 검색광고 콘솔 접속

```
사장님, 먼저 네이버 검색광고 계정이 필요해요.

📍 다음 주소를 브라우저에서 열어 주세요:
https://manage.searchad.naver.com/customers

→ 사장님 네이버 아이디로 로그인하시면 검색광고 관리 페이지가 열립니다.

광고 계정이 이미 있으시면 → "있어" 또는 "다음"
처음이시면 → "처음이야" (가입 안내 드릴게요)

로그인 후 우측 상단에 보이는 **Customer ID(숫자)** 도 메모해 주세요.
```

### 2단계 — API 사용 관리 페이지에서 키 발급 + 메모장에 임시 저장

사장님이 "다음" 하면:

```
좋아요. 이제 키 2개를 발급하겠습니다.

📍 같은 페이지에서:
   상단 메뉴 → "도구" → "API 사용 관리" 클릭

📍 페이지가 열리면:
   "API 라이선스 발급" 버튼 → 약관 동의 → 발급

발급되면 화면에 2개 값이 나옵니다:
   - API 키 (영문+숫자 짧은 문자열)
   - 비밀 키 (긴 문자열, ⚠️ 화면 닫으면 다시 못 봅니다)

🔒 **두 값과 Customer ID를 사장님 컴퓨터의 메모장(텍스트 파일)에 임시 저장해 주세요.**
   - 카카오톡, 메일, 캡처 X (외부 유출 위험)
   - 채팅창에도 알려주지 마세요 — 김태대리는 키를 보지 않습니다

복사하셨으면 → "복사했어" 또는 "다음"
비밀 키를 놓치셨으면 → "다시 발급할게" (재발급 안내)
```

### 3단계 — `.env` 파일 직접 편집 (사장님이 직접 / Claude은 안 봄)

사장님이 "복사했어" / "다음" 하면:

```
좋아요. 이제 메모장에 적어두신 키 3개를 사장님 컴퓨터의 `.env` 파일에 옮겨 적을 거예요.

🔒 김태대리는 사장님 키를 절대 보지 않습니다.
   사장님이 직접 `.env` 파일을 편집하시고, 저는 검증·실행만 돕습니다.

📖 메모장 키 3개를 `.env` 로 옮기는 단계별 가이드:
   prompts/02b-edit-env.md  (Mac / 윈도우 별도 안내)

편집 끝나시면 채팅창에 이렇게 말씀하세요:
"키 입력 끝났어. 검증해줘"
```

→ 사장님 "키 입력 끝났어" → Claude 이 `scripts/verify_keys.py` 실행 → 인증 성공 여부만 출력 (키 값 마스킹 표시).

→ 검증 후 메모장에 적어둔 키는 **반드시 삭제**하도록 안내. `.env` 파일이 영구 저장소입니다.

---

## ⚠️ 보안 주의 — Claude 행동 규칙

만약 사장님이 채팅에 API 키를 입력하려고 하면:
1. **즉시 거부**: "사장님, API 키는 제가 보지 않는 게 안전해요"
2. `prompts/02b-edit-env.md` 가이드로 안내
3. 만약 이미 입력하셨다면: **즉시 네이버 콘솔에서 키 재발급 권고** (Anthropic 서버에 키가 노출됐을 수 있음)

마스킹: `verify_keys.py` 는 키를 `••••1234` 형식으로만 출력합니다. 절대 풀어서 보여주지 마세요.

영상 촬영 시 키 입력·`.env` 편집 부분은 모자이크·편집 권장.

## 사장님이 모르는 게 있을 때

- "Customer ID가 어딨어요?" → "검색광고 관리 페이지 우측 상단, 사장님 이름 옆 숫자입니다"
- "비밀 키를 못 봤어요" → "괜찮아요. 같은 페이지에서 다시 발급받으시면 새 비밀 키가 나옵니다"
- "광고 계정이 없어요" → 네이버 광고주 가입 안내 (시간 더 걸림, 별도 영상 추천)
