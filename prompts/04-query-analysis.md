# 🔍 04 — 비효율 검색어 분석 + 부정 키워드 등록

## 사장님이 채팅에 입력할 한 마디

> **"비효율 검색어 찾아줘"**

또는

> **"광고비 새는 검색어 분석해줘"**

또는

> **"부정 키워드 추천해줘"**

---

## Claude 절차

### Step 1 — 광고 데이터 상태 확인 (사장님 모름)

내부적으로 확인:
1. `keywords.yaml` 존재? (없으면 setup 안내)
2. 검색어 데이터 (DB의 `search_queries`) 비어있나? (없으면 fetch 권유)
3. 데이터가 며칠 전 거? (오래되면 새로 받기 권유)

→ 사장님에게는 **"광고 데이터"** 라는 단어로만:

```
사장님, 분석하려면 먼저 광고 데이터를 받아와야 해요. 
네이버 서버에서 1~3분 정도 걸려요. 받아올까요?
```

또는 (이미 데이터 있고 최근이면):

```
지난번에 받아둔 광고 데이터로 바로 분석할게요.
```

또는 (오래된 데이터):

```
이전에 받은 데이터가 N일 전 거예요. 새로 받는 게 좋겠어요. 받아올까요?
```

### Step 2 — 데이터 받기 (필요한 경우만)

```bash
python -m powerlink_pilot fetch-stats --days 7 --type search
```

진행 상황을 한국어로 보여줌 (Claude이 출력 그대로 패스 — 이미 한국어).

### Step 3 — 분석

```bash
python -m powerlink_pilot analyze
```

→ 비효율 검색어 후보 리스트 출력. 룰별 그룹 + severity 표시됨.

### Step 4 — 사장님 확인 + 등록

분석 결과 보여준 후:

```
이 중 부정 키워드로 등록할까요? (y/n)
```

사장님 'y' 응답 시:

```bash
python -m powerlink_pilot analyze --apply --yes
```

→ 미리보기 + 등록 결과를 한국어로 보고.

---

## 🎬 데모 모드 (영상 1편 시연용)

사장님 본인 데이터 없는 시청자를 위해 합성 데이터로 시연:

```bash
python -m powerlink_pilot analyze --sample
```

→ 가상 검색어 10개로 비효율 5개 발견 데모. **API 키 불필요**.

영상에서 보여줄 흐름:
1. "사장님, 김태대리가 광고 데이터 분석해서 광고비 새는 곳 찾아드릴게요"
2. `analyze --sample` 실행
3. 결과 화면 한국어 요약 ("아 정말 광고비 새는 검색어 3개 발견됐네요")
4. "실제 사장님 광고도 똑같이 분석합니다. 영상 설명란 참고하세요"

## 사장님이 막혔을 때

| 증상 | 원인 | 대응 |
|---|---|---|
| "분석할 데이터가 없다" 메시지 | fetch-stats 안 했음 | `fetch-stats` 안내 |
| fetch-stats 가 5분 이상 진행 안 됨 | Naver 서버 폭주 또는 데이터 양 ↑ | "잠시 후 재시도" 안내. 그래도 안 되면 99-help.md |
| 추천 0건 | 데이터 부족 또는 사장님 광고가 효율 좋음 | "축하해요. 비효율 신호가 없어요" + "더 누적되면 더 정확해진다" |
| 등록 실패 (API 오류) | rate limit 또는 키 만료 | 99-help.md 진단 |
